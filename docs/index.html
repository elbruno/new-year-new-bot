The proposed design

A tiny robot, with a .NET brain

The robot handles sensing and expression. A local .NET backend coordinates behavior, AI services, and observability, with clear boundaries around private work context.

01 · The expressive edge

StackChan runs C++ firmware and connects over Wi-Fi. The first goal is a simple, reliable link for expressions, gestures, and service responses.

02 · The .NET brain

ASP.NET Core services own the companion’s behavior and controls. Aspire helps run the services together and inspect application health and traces.

03 · AI, with guardrails

Foundry and agent technologies are proposed for later episodes. Work-context demonstrations start with synthetic data; private details stay out of public robot alerts.

Project status: this is an evolving design. Hardware behavior, AI integrations, WorkIQ access, and the livestream plan require validation. Early demos can use a simulator and synthetic data so viewers can follow along without a device or work-account access.
